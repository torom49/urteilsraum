FACHLICH VERANKERT

Kriterien machen Urteile nachvollziehbar.

Die App verteilt Denkaufträge. Die Urteilsbildung bleibt bei den Lernenden.

So arbeitet ihr mit der App

  1. Gemeinsame Frage lesen und Begriffe klären.
  2. Die zugewiesene Position anhand aller drei Kriterien begründen. Für jedes Argument einen Beleg oder eine überprüfbare Annahme anführen.
  3. Mit einer Person der Gegenseite austauschen und das stärkste Gegenargument prüfen.
  4. Die Rolle verlassen, Kriterien gewichten und ein eigenes Urteil formulieren.

Beispielstruktur: „Unter dem Kriterium … spricht für/gegen die Maßnahme, dass … . Das lässt sich begründen durch … . Ein Beleg ist … . Einschränkend gilt … .“

Belege recherchiert ihr im Unterrichtsmaterial oder in geeigneten Quellen. Die App liefert keine vorgegebenen politischen Antworten.

Offizielles Verzeichnis prüfen ↗

Die Fragen wurden für diese App formuliert; sie sind keine offiziellen Prüfungsaufgaben. „eA“ markiert eine ausgewählte Vertiefung, keine vollständige Niveauzuordnung. Jahrgangsspezifische Abiturhinweise und das schulinterne Curriculum müssen ergänzend berücksichtigt werden.

Was gespeichert wird

Runde, Fragenauswahl und bearbeitete Kriterien bleiben lokal in diesem Browser gespeichert. Es werden keine Namen, Konten oder Schülerantworten benötigt. Auf einem anderen Gerät wird keine gemeinsame Live-Runde synchronisiert.

Die App kann direkt über index.html geöffnet oder als statische Website auf GitHub Pages bereitgestellt werden. Es gibt keine externen Schriftarten, Analysewerkzeuge oder KI-API-Aufrufe.

Zufall mit ausgewogener Verteilung

Pro und Contra werden zufällig mit möglichst gleich großen Gruppen vergeben. Kriterien werden innerhalb jeder Kategorie aus gemischten Stapeln gezogen, bevor ein neuer Stapel beginnt. Eine Person erhält drei unterschiedliche Kriterien.

Fragen werden aus dem aktiven, gefilterten Pool gezogen. Derselbe Pool wird zunächst durchlaufen, bevor Fragen erneut vorkommen. „Nur Rollen neu losen“ behält die gemeinsame Frage bei.
